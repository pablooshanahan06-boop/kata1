# Kata 1 - ULPGC

## Objetivo
El objetivo de esta entrega es familiarizarse con el entorno de desarrollo (IntelliJ IDEA), el control de versiones con Git/GitHub y los fundamentos de Java. Se ha implementado un modelo de datos `Person` utilizando la estructura `record` y calculando la edad de la persona a partir de su fecha de nacimiento mediante la librería `java.time`.
